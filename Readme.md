# *Return to Brutal Wolfenstein*

<br>

## About _**RtBW**_
An extremely Work-In-Progress rework and rewrite of *ZioMcCall's Brutal Wolfenstein*. <br>
As vanilla Brutal Wolfenstein and Brutal Wolfenstein II are still relying on a poorly written codebase, we hope that Zio and his team will be able to make use of the reworked code in this project to make those mods even better in their own regard.

Main focus for the mod are as follower (since some people seem to have it completely misunderstood):
* Improving gameplay functionality and reducing bugs and jank.
* Rewriting the codebase to not rely on ACS junk and archaic BD code.
* Leaning a bit more into the arcadey feel of DOS Wolfenstein, with some minor influence from modern score/combo systems.
* Weapon swapping while reloading, plus other actions while reloading.
* More enemy variety, giving them different weapons to match the weapons the player can wield as well.
* PB quality weapon sprites and animations.


## Features
* Nashgore driven gore system
* Enhanced enemy AI with memory and more fluid flow
* Enhanced sound/visual effects, taking full advantage of the engines capabilities
* (Heavily WIP) Improved weapon sprites/code/animations
* 66% less actors than your favorite brutal fork!
